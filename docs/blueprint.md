# **App Name**: PatientPal

## Core Features:

- Patient Registration: Allow doctors to create new patient profiles including basic information (name, contact details, medical history).
- Prescription Recording: Enable doctors to record prescriptions for each patient, including medication name, dosage, and instructions.
- Appointment Scheduling: Schedule and display upcoming appointments for each patient.
- Appointment Reminders: Display patients with upcoming appointments.

## Style Guidelines:

- Primary color: Soft blue (#B3E5FC) for a calming and professional feel.
- Secondary color: Light grey (#EEEEEE) for backgrounds and neutral elements.
- Accent: Teal (#009688) for key actions and highlights, conveying trust and reliability.
- Clear and readable font for medical information.
- Use simple, recognizable icons for common actions and data categories.
- Clean, well-organized layout with clear sections for patient information, prescriptions, and appointments.
